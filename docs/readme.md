# ForgePoint.Identity documentation

This folder is the protocol and configuration documentation for ForgePoint.Identity. Pages are authored in ReStructuredText (RST). New features such as PAR are also described in the repository README.

A primer for RST is [here](http://www.sphinx-doc.org/en/stable/rest.html). Sphinx configuration is in `conf.py`.
