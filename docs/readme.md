# ForgePoint.Identity documentation

This folder is the protocol and configuration documentation for ForgePoint.Identity. Pages are authored in ReStructuredText (RST). Pushed Authorization Requests, health checks, and the CVE-2024-39694 local-URL fix are documented here as well as in the repository README.

A primer for RST is [here](http://www.sphinx-doc.org/en/stable/rest.html). Sphinx configuration is in `conf.py`.
